# Auditoría de calidad y accesibilidad - TECGo

## 1. Formateo del código

Se utilizó Prettier para organizar y mejorar la legibilidad del código HTML y CSS del proyecto.

## 2. Auditoría con Lighthouse

Se realizó una auditoría mediante Lighthouse, integrado en Chrome DevTools, utilizando Google Chrome y la extensión Live Server para visualizar el sitio localmente.

Se evaluaron las siguientes categorías:

- Rendimiento (Performance).
- Accesibilidad (Accessibility).
- Buenas prácticas (Best Practices).
- SEO.

## 3. Corrección de fallas de accesibilidad

Se revisaron los resultados de Lighthouse para identificar posibles problemas de accesibilidad.

Se verificaron los siguientes elementos:

- Textos alternativos en imágenes mediante el atributo `alt`.
- Nombres descriptivos en botones y enlaces.
- Etiquetas en campos de formularios.
- Contraste entre texto y fondo.
- Jerarquía correcta de encabezados HTML.
